    7. Internationalization

    7.1. Example 21: A Bilingual Application

    A bilingual application has three types of text to translate:

    • application text: labels and messages. These are stored in dictionaries, one per language;
    • dates and amounts: the [intl] package (see Example 09), in the default language;
    • text from the [Flutter] package itself: the buttons on its windows, the days and months in its calendar. The [flutter_localizations] package provides these.

    // =========================================================================
// lib/ex21_i18n/traductions.dart - dictionaries, a common language
// -------------------------------------------------------------------------
// Each language has its own DICTIONNAIRE, a JSON file included with
// the application (assets/i18n/ex21_fr.json, ex21_en.json), where each text
// has a CLÉ ("ACCUEIL.BONJOUR"):
//    - t('ACCUEIL.BONJOUR', {'name': 'Marie'}): the text in the language
//      COURANTE, where the {{name}} parameters are replaced;
//    - t('ACCUEIL.RENDEZ_VOUS', {'count': n}): a plural text; it
//      chooses the key RENDEZ_VOUS_zero, _one, or _other depending on n and the rules
//      of the language (in French, 0 and 1 are singular; in English,
//      only 1);
//    - changerLangue('en'): loads the other dictionary and notifies the
//      screens (a ChangeNotifier), which are then re-translated.
// These are the conventions of the JavaScript i18next library: the
// dictionaries are those of the Vue.js, Angular, and React clients of
// RdvMedecins... and the server, which returns only CLÉS
// ("ERRORS.LOGIN_TAKEN"), also uses them.
// =========================================================================

import 'dart:convert';

import 'package:flutter/services.dart';
import 'package:flutter/widgets.dart';
import 'package:intl/intl.dart';
import 'package:shared_preferences/shared_preferences.dart';

const langues = ['fr', 'en'];

class Traductions extends ChangeNotifier {
  final String _prefixe; // the dictionaries: assets/i18n/<prefix>_<language>.json
  final SharedPreferences? _stockage;
  String _langue = 'fr';
  Map<String, Object?> _dictionnaire = {};

  Traductions(this._prefixe, [this._stockage]);

  String get langue => _langue;

   // the source language: the one stored on the device, otherwise the language of the
   // phone (if known), otherwise French
  Future<void> demarrer() async {
    final memorisee = _stockage?.getString('$_prefixe.langue');
    final appareil = WidgetsBinding.instance.platformDispatcher.locale.languageCode;
    await changerLangue(memorisee ?? (langues.contains(appareil) ? appareil : 'fr'));
  }

  Future<void> changerLangue(String langue) async {
     // rootBundle: files included with the app (the "assets" section of the pubspec)
    final json = await rootBundle.loadString('assets/i18n/${_prefixe}_$langue.json');
    _dictionnaire = jsonDecode(json) as Map<String, Object?>;
    _langue = langue;
    await _stockage?.setString('$_prefixe.langue', langue);
    notifyListeners();
  }

   // "ACCUEIL.BONJOUR" -> dictionaryQZXW2HTMLBWydBQ0NVRUlMJ10ZQXQZXW2HTMLBWydCT05KT1VSJ10ZQX; null if absent
  String? _chercher(String cle) {
    Object? noeud = _dictionnaire;
    for (final partie in cle.split('.')) {
      noeud = noeud is Map<String, Object?> ? noeud[partie] : null;
    }
    return noeud is String ? noeud : null;
  }

  String t(String cle, [Map<String, Object?> params = const {}]) {
    String? texte;
    final count = params['count'];
    if (count is int) {
       // Intl.pluralLogic: the plural form, according to the rules of the language
      texte = Intl.pluralLogic(
        count,
        locale: _langue,
        zero: _chercher('${cle}_zero'),
        one: _chercher('${cle}_one'),
        other: _chercher('${cle}_other'),
      );
    }
    texte ??= _chercher(cle);
     // an unknown key is displayed as-is: you can immediately see what’s missing
    if (texte == null) return cle;
     // {{name}} -> the value of the “name” parameter
    return texte.replaceAllMapped(RegExp(r'\{\{(\w+)\}\}'), (m) => '${params[m[1]] ?? m[0]}');
  }
}
    • lines 30–34: the translations: a [ChangeNotifier] (the screens will be rebuilt when the language changes), which retains the current language and its dictionary;
    • lines 42–45: the source language: the one stored on the device, otherwise the phone’s language (if known), otherwise French;
    • lines 48–54: change language: load the dictionary, a JSON file included with the application ([rootBundle.loadString] reads a file from the [assets] section of [pubspec.yaml]), decode it ([jsonDecode]), save the selection, and update the screens;
    • lines 58–63: search for a key “ACCUEIL.BONJOUR” in the dictionary: it traverses, section by section, the nested JSON objects. [noeud is Map<String, Object?> ? ... : null]: a type check, which “promotes” the variable in the branch where it is true;
    • Lines 66–83: the translation. For a plural (an integer parameter [count]), [Intl.pluralLogic] chooses the form according to the language rules: in French, 0 and 1 are singular; in English, only 1. An unknown key is displayed as-is: you can immediately see what’s missing. Finally, each [{{nom}}] is replaced by the parameter’s value.

    Why not use the official [Flutter] tool? [Flutter] offers a generator ([flutter gen-l10n]) that creates, from [.arb] files, a class with one method per text ([AppLocalizations.of(context).bonjour('Marie')]): The keys are validated at compile time. This is the best solution for an application where all texts are known in advance. But our server returns keys (“ERRORS.LOGIN_TAKEN”) that need to be translated at runtime: a dictionary, which is queried by the key, is much better suited for this purpose and allows us to share dictionaries with other clients.

    // =========================================================================
// lib/ex21_i18n/main.dart - a bilingual application
// -------------------------------------------------------------------------
//    - the application’s TEXTES files: the dictionaries (traductions.dart),
//      provided to all screens by the provider (see example 20);
//    - dates and amounts: the intl package, in the current language
//      (see example 09);
//    - Flutter texts LUI-MÊME (the calendar, its buttons, etc.): the
//      localization "delegates" of the flutter_localizations package, which
//      follow the locale property of MaterialApp.
// Changing the language re-renders the entire screen without restarting.
// =========================================================================

import 'package:flutter/material.dart';
import 'package:flutter_localizations/flutter_localizations.dart';
import 'package:intl/date_symbol_data_local.dart';
import 'package:intl/intl.dart';
import 'package:provider/provider.dart';
import 'package:shared_preferences/shared_preferences.dart';

import 'traductions.dart';

// what the server RdvMedecins would return (see the chapter on the black box)
const reponsesServeur = [
  (statusCode: 409, cle: 'ERRORS.LOGIN_TAKEN', params: <String, String>{}),
  (statusCode: 429, cle: 'ERRORS.TOO_MANY_ATTEMPTS', params: {'minutes': '15'}),
];

// context.t('CLE'): a shortcut, via an extension of BuildContext
extension Traduire on BuildContext {
  String t(String cle, [Map<String, Object?> params = const {}]) => watch<Traductions>().t(cle, params);
}

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await initializeDateFormatting();
  final traductions = Traductions('ex21', await SharedPreferences.getInstance());
  await traductions.demarrer();
  runApp(ChangeNotifierProvider.value(value: traductions, child: const Application()));
}

class Application extends StatelessWidget {
  const Application({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
       // onGenerateTitle: the application title, translated
      onGenerateTitle: (context) => context.t('APP.TITRE'),
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      locale: Locale(context.watch<Traductions>().langue),
      supportedLocales: [for (final l in langues) Locale(l)],
      localizationsDelegates: GlobalMaterialLocalizations.delegates,
      home: const PageTraduite(),
    );
  }
}

class PageTraduite extends StatefulWidget {
  const PageTraduite({super.key});

  @override
  State<PageTraduite> createState() => _PageTraduiteState();
}

class _PageTraduiteState extends State<PageTraduite> {
  int _nombre = 2;
  final _aujourdhui = DateTime.now();

  @override
  Widget build(BuildContext context) {
    final traductions = context.watch<Traductions>();
    final langue = traductions.langue;
     // instructors in the language COURANTE
    final date = DateFormat.yMMMMEEEEd(langue).format(_aujourdhui);
    final prix = NumberFormat.currency(locale: langue, name: 'EUR', symbol: '€').format(1234.5);

    return Scaffold(
      appBar: AppBar(
        title: Text(context.t('APP.TITRE')),
        actions: [
           // languages: "segmented" buttons
          Padding(
            padding: const EdgeInsets.only(right: 8),
            child: SegmentedButton<String>(
              showSelectedIcon: false,
              segments: [for (final l in langues) ButtonSegment(value: l, label: Text(l.toUpperCase()))],
              selected: {langue},
              onSelectionChanged: (choix) => traductions.changerLangue(choix.first),
            ),
          ),
        ],
      ),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Card(
            child: Padding(
              padding: const EdgeInsets.all(12),
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  Text(context.t('ACCUEIL.BONJOUR', {'nom': 'Marie'})),
                  Text(context.t('ACCUEIL.AUJOURDHUI', {'date': date})),
                  Text(context.t('ACCUEIL.PRIX', {'prix': prix})),
                  const SizedBox(height: 8),
                   // count: selects the plural form and replaces {{count}}
                  Text(
                    context.t('ACCUEIL.RENDEZ_VOUS', {'count': _nombre}),
                    style: const TextStyle(fontWeight: FontWeight.bold),
                  ),
                  Wrap(
                    spacing: 8,
                    children: [
                      TextButton(onPressed: () => setState(() => _nombre++), child: Text(context.t('ACCUEIL.AJOUTER'))),
                      TextButton(
                        onPressed: _nombre == 0 ? null : () => setState(() => _nombre--),
                        child: Text(context.t('ACCUEIL.RETIRER')),
                      ),
                    ],
                  ),
                   // the Flutter calendar: its text follows the language of MaterialApp
                  OutlinedButton.icon(
                    icon: const Icon(Icons.calendar_month),
                    label: Text(context.t('ACCUEIL.CALENDRIER')),
                    onPressed: () =>
                        showDatePicker(context: context, firstDate: DateTime(2026), lastDate: DateTime(2027, 12, 31)),
                  ),
                ],
              ),
            ),
          ),
          Card(
            child: Padding(
              padding: const EdgeInsets.all(12),
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  Text(context.t('SERVEUR.TITRE'), style: Theme.of(context).textTheme.titleSmall),
                  Text(context.t('SERVEUR.EXPLICATION')),
                  const SizedBox(height: 8),
                   // the server key EST is a dictionary key; `params` provides its parameters
                  for (final r in reponsesServeur) ...[
                    Text('${r.statusCode} ${r.cle}', style: const TextStyle(fontFamily: 'RobotoMono', fontSize: 12)),
                    Text('→ ${context.t(r.cle, r.params)}'),
                    const SizedBox(height: 6),
                  ],
                ],
              ),
            ),
          ),
        ],
      ),
    );
  }
}
    • lines 30–31: an extension of [BuildContext] (see Example 09): [context.t('CLE')] reads the translations provided above, subscribes to updates, and performs the translation;
    • lines 36–38: initialization: the names of the days and months in all languages, followed by the translations;
    • line 39: [ChangeNotifierProvider.value] returns a DÉJÀ object created (by [main]);
    • line 50: the application title, translated;
    • lines 52–54: the language of [Flutter] itself follows that of the application;
    • lines 76–77: the date and price, formatted in the current language, then passed as parameters to the text strings;
    • lines 86–90: the language selection in the top bar;
    • line 110: [count] selects the plural form and replaces [{{count}}];
    • lines 124–128: the calendar for [Flutter]: its texts follow the language of [MaterialApp];
    • lines 144–146: what the server [RdvMedecins] would return: a key and its parameters. The key from the server EST is a key from the dictionary.
